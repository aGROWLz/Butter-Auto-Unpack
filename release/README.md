- 🔍 7z自动格式检测，支持伪装扩展名的压缩包
- 📦 集成Bandizip解压引擎，支持更多压缩格式
- 🔄 递归处理子文件夹，自动检索嵌套压缩包
- 📂 GUI显示解压文件夹路径，一键打开文件夹
- 📋 文件列表新增解压文件夹列和打开按钮
- 🎯 增强状态跟踪：未解压、包已删除、已删除状态
- ▶️ 手动解压功能，支持密码保护压缩包
- 🗑️ 统一删除确认对话框，避免重复弹窗
- ✅ 优化复选框样式，修复左右黑边问题
- 🔧 修复Windows路径分隔符和系统文件误识别
- 🎨 状态颜色区分和操作按钮动态显示

## 使用说明

1. 配置目标文件夹和解压文件夹
2. 设置解压密码库（可选）
3. 启动监控
4. 将压缩包放入目标文件夹，程序会自动处理

## 系统要求

- Windows 10/11
- 7-Zip 工具（程序会自动检测）
- Python 3.8+ （如果从源码运行）
